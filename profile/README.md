# YCU-Algo-Lab

ACM 算法集训队专注于数据结构与算法研究，以及程序设计竞赛（ACM/ICPC、CCPC、GPLT 等）的日常训练与实战。

## 竞赛荣誉

* **CCPC 中国大学生程序设计竞赛（区域赛）**：银牌
* **ICPC 国际大学生程序设计竞赛（全国邀请赛）**：铜牌
* **CCPC 中国大学生程序设计竞赛（全国邀请赛）**：铜牌
* **CCPC 中国大学生程序设计竞赛（全国邀请赛）**：铜牌

## 训练与研究方向

* **数据结构与基础算法**：动态规划、图论、线段树、树状数组、并查集等。
* **算法应用与实现**：A* 寻路、Dijkstra、最小生成树、元胞自动机及底层网格算法。

## 技术栈与平台

* **语言**：C++、C#、C
* **训练平台**：Codeforces、LeetCode、牛客、洛谷、PTA

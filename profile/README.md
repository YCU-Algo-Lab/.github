## 📚 训练方向

我们的核心训练领域包括：

* 🔹 **数据结构**：线段树、树状数组、并查集、字典树、平衡树等。
* 🔹 **基础算法**：动态规划 (DP)、图论（最短路、最小生成树）、计算几何、数论与组合数学。
* 🔹 **策略与应用**：贪心、构造、时间与空间复杂度优化。
